小学练习 · 专用平板

做成默认桌面：做题攒分，满 40 分可玩 10 分钟（只算亮屏时间），到点回到练习。

计分跟网页一样：多数题对一题 1 分，乘法口诀对一题 0.25 分。

下载 APK

这个按钮指向仓库里的 downloads/primary-school.apk。推到 GitHub 后，GitHub Pages 就能下；也可以改成 Release 地址（见下面第 5 节）。

1. 装到平板

  1. 设置里打开「未知来源 / 允许安装未知应用」
  2. 用浏览器打开本页，下载并安装
  3. 打开 App，按提示打开通知、使用情况访问、电池优化；在「后台保活」里按说明手动设置。选「小学练习」为默认桌面
  4. 点右上角人形图标，设家长密码；以后也可在家长菜单里再开「打开计时权限」

1.1 找不到「自启动 / 后台运行」时

  1. 设置 → 应用 → 小学练习 → 电池 / 耗电，选「不限制」或「允许后台」
  2. 上划多任务，长按「小学练习」，点锁定（小锁）
  3. 设置里搜索「自启动」「后台」，有的话把小学练习打开

很多学习平板根本没有自启动菜单，只能做到上面两步。仍经常被杀，就需要第 2 节用电脑设设备所有者。

2. 设成设备所有者（只有专用平板才需要电脑）

普通使用打开第 1 步那些权限即可计时、到点拉回。要锁死系统桌面、防止小孩改回去，才需要设备所有者。先恢复出厂或确保没登录 Google 账号，电脑装好 adb 后：

adb install -r primary-school.apk
adb shell dpm set-device-owner com.zhiwei.primaryschool/.KioskAdminReceiver

成功后：不能卸载、强制当桌面、练习模式出不去、时间到会灭屏。

要取消设备所有者（会清数据）：

adb shell dpm remove-active-admin com.zhiwei.primaryschool/.KioskAdminReceiver

3. 日常

  • 做题，顶栏积分到 40，点「玩 10 分钟」
  • 出现应用列表，去玩游戏；右上角倒计时每秒跳动，关掉屏幕不计时
  • 游戏里上划不应回到系统桌面；点橙色倒计时可回应用列表
  • 10 分钟亮屏后会把游戏挂起并回到练习
  • 家长：密码 → 系统设置 / 赠送 40 分 / 改网址

退出桌面锁定

  1. 点右上角人形图标，第一次会让你设家长密码（至少 4 位），之后输入密码
  2. 选「打开系统设置」
  3. 默认应用 → 桌面应用，改回平板原来的桌面

如果做过设备所有者，设置里改不掉桌面，用电脑：

adb shell dpm remove-active-admin com.zhiwei.primaryschool/.KioskAdminReceiver

4. 在 Mac 上编译

本机已装过的话，在仓库里执行：

export JAVA_HOME="$HOME/Library/Java/JavaVirtualMachines/temurin-17.jdk/Contents/Home"
export ANDROID_HOME="$HOME/Library/Android/sdk"
cd android
./gradlew assembleDebug
cp app/build/outputs/apk/debug/app-debug.apk ../downloads/primary-school.apk

新环境（Apple Silicon Mac）要先装 JDK 17 和 Android SDK，不必装 Android Studio。

  1. JDK 17（Temurin）：从清华镜像下 OpenJDK17U-jdk_aarch64_mac_hotspot_*.tar.gz，解压到 ~/Library/Java/JavaVirtualMachines/temurin-17.jdk（目录里要有 Contents/Home）。
  2. 命令行工具： commandlinetools-mac 解压到 ~/Library/Android/sdk/cmdline-tools/latest/。
  3. 安装平台（或按上面那样从 Google 直接下 zip 再解压）： 
    yes | sdkmanager --sdk_root="$ANDROID_HOME" --licenses
sdkmanager --sdk_root="$ANDROID_HOME" \
  "platforms;android-34" "build-tools;34.0.0" "platform-tools"
  4. 在 android/local.properties 写一行（此文件不进 git）： 
    sdk.dir=/Users/你的用户名/Library/Android/sdk

也可安装 Android Studio，打开 android/ 文件夹，菜单 Build → Build APK(s)。

5. 从网站提供下载

两种做法都可以，APK 大约 5 MB。

A. 跟网页一起推到 GitHub Pages（简单）

  • 把编好的包放到 downloads/primary-school.apk
  • commit 并 push 到 GitHub（和现在的 Pages 同一仓库）
  • 地址就是： https://zhiweitian.github.io/primary_school/downloads/primary-school.apk

GitHub 单文件建议小于 50 MB，这个 APK 没问题。缺点是二进制会进 git 历史，以后每次改包仓库会变大一点。

B. GitHub Release（包多了更合适）

  • 在 GitHub 仓库发一个 Release，把 APK 当附件上传
  • 把本页下载按钮改成： https://github.com/zhiweitian/primary_school/releases/latest/download/primary-school.apk

现在只有一个包、更新不勤，用 A 即可：编完拷到 downloads/，跟网页一起 push。
